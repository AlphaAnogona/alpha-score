# alpha-score
Chrome extension that shows trust ratings for crypto projects on any website

     Detects token mentions on any website and shows emoji badges:
     - 💎 Diamond - legit, battle-tested
     - 🤡 Clown - degen play
     - 🗑️ Trash - suspicious
     - 🚩 Red Flag - confirmed scam

     ## Features
     - Works on any website
     - History Scanner - check your browsing history for crypto projects
     - Customizable badge position and size
     - 100% local, zero tracking
